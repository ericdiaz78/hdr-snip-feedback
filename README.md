# HDR Snip feedback

Bug reports and feature requests for **HDR Snip**, a Windows 11 screen capture tool that gets HDR right: every snip is saved as a share-safe image that looks correct on any screen, plus an HDR copy.

## Report a bug

The quickest way is from the app: **Settings > Report a bug**. It copies a report to your clipboard with your user name, PC name and profile folder removed, then opens the form here. Paste it in, add what happened, and read it over before you send.

Or [open a bug report](../../issues/new?template=bug.yml) directly.

## What happens next

New reports are reviewed, and fixes ship as updates through the Microsoft Store. Please do not post screenshots that contain private information; this tracker is public.
